# Known Issues

Current broken, incomplete, or at-risk parts of this repo. Prevents re-discovery across sessions.

## How to use

- Add entries to **Active** when you find a broken piece you cannot fix this session.
- Each entry format: `- <description> | area: <feature/area> | <date>`
- When a fix is verified, move the entry to **Resolved** with a resolution date.
- When Resolved has more than 10 entries, move the oldest to `memory/KNOWN-ISSUES-ARCHIVE.md`.
- The archive file is never read automatically -- only consulted when investigating recurring patterns.
