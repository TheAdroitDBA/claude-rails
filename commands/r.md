Review the changed code:

1. Run /simplify on all recently changed files.

2. Check for reuse opportunities: is any new code duplicating logic that already exists elsewhere in the repo? If so, propose the consolidation.

3. Check for quality and efficiency: unclear naming, missing error handling, unnecessary complexity, or performance issues obvious from reading.

4. Fix any issues found, or record them as /b entries if they are out of scope for this session.
